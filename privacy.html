개인정보처리방침

PLUS2.5 (com.lwd20.traininglog) · 최종 수정 2026년 9월 7일

요약. 이 앱에는 서버가 없습니다. 기록한 운동·체중·섭취 자료는 기기 안에만 저장되며 개발자에게 전송되지 않습니다. 개발자는 이용자의 어떤 자료도 수집하거나 보관하지 않습니다. 자료가 기기 밖으로 나가는 경우는 이용자가 직접 AI 리포트를 실행했을 때 하나뿐이며, 그때도 이용자 본인이 등록한 API 키로 이용자가 고른 AI 업체에 직접 전송됩니다.

1. 앱이 다루는 자료

자료어디서어디에 저장
운동 기록 (종목·중량·반복·세트)이용자가 직접 입력기기 내부
체중·체지방률·골격근량이용자 입력 또는 헬스 커넥트기기 내부
섭취 열량·영양소헬스 커넥트 (삼성헬스 등이 기록한 것)기기 내부
앱 설정 (목표치·테마 등)이용자가 직접 설정기기 내부
AI API 키이용자가 직접 입력 (선택)기기 내부

저장 위치는 앱 내부 저장소이며, 앱을 삭제하면 함께 삭제됩니다.

2. 헬스 커넥트 (Health Connect)

이 앱은 안드로이드 헬스 커넥트에서 다음 두 가지를 읽기만 합니다. 쓰거나 수정하지 않습니다.

  • android.permission.health.READ_NUTRITION — 섭취 열량과 영양소
  • android.permission.health.READ_WEIGHT — 체중

왜 필요한가

  • 섭취 영양 — 소비 열량과 견주어 하루 적자를 계산하고, 단백질 섭취량을 목표치와 비교하기 위해서입니다.
  • 체중 — 주당 감량 속도를 계산하고 목표 도달 시점을 추정하기 위해서입니다.

어떻게 다루는가

  • 읽어 온 값은 기기 안에만 보관되며 개발자에게 전송되지 않습니다.
  • 이 자료를 광고·마케팅에 사용하지 않으며, 데이터 중개업자나 정보 서비스 기관을 포함한 제3자에게 판매하거나 제공하지 않습니다.
  • 권한은 언제든 안드로이드 설정 > 헬스 커넥트에서 철회할 수 있습니다. 철회하면 앱은 더 이상 자료를 읽지 않습니다.
  • 앱을 삭제하면 앱이 보관하던 사본도 함께 삭제됩니다.

3. 자료가 기기 밖으로 나가는 유일한 경우 — AI 리포트

AI 리포트는 선택 기능이며 기본으로 꺼져 있습니다. 이용자가 본인의 API 키를 직접 등록하고 리포트 생성을 누른 경우에만 동작합니다.

  • 전송되는 것: 분석에 필요한 운동 기록과 체중·섭취 요약
  • 전송되는 곳: 이용자가 고른 업체 한 곳 — Google (Gemini), OpenAI, Anthropic
  • 전송은 이용자 본인 명의의 API 키로 이루어지며, 개발자는 이 통신에 관여하지 않고 내용을 볼 수 없습니다.
  • 전송된 자료의 처리는 해당 업체의 개인정보처리방침을 따릅니다. 위 링크에서 확인하십시오.
  • API 키는 기기 안에만 저장되며 백업 파일에 포함되지 않습니다.

건강 자료를 AI 업체에 보내고 싶지 않다면 API 키를 등록하지 마십시오. 등록하지 않으면 이 기능은 동작하지 않으며, 나머지 기능은 모두 정상적으로 쓸 수 있습니다.

4. 개발자가 수집하지 않는 것

이 앱에는 개발자가 운영하는 서버가 없습니다. 따라서 다음을 일절 수집하지 않습니다.

  • 이용자 계정 — 회원가입이 없습니다
  • 이름·이메일·전화번호 등 신원 정보
  • 위치 정보
  • 연락처·사진·통화기록
  • 광고 식별자, 사용 통계, 분석 도구 — 일절 사용하지 않습니다
  • 기기 식별자

5. 백업

  • 앱은 주기적으로 기록을 기기의 다운로드 폴더에 파일로 저장합니다. 이 파일은 기기 안에 있으며 어디로도 전송되지 않습니다.
  • 이용자가 직접 내보내기를 눌러 파일로 저장할 수도 있습니다. 그 파일을 어디에 두고 누구와 공유할지는 전적으로 이용자의 선택이며, 그 이후는 개발자가 관여할 수 없습니다.
  • 백업 파일에는 API 키가 포함되지 않습니다.

6. 보관과 삭제

  • 개발자가 보관하는 자료가 없으므로 개발자 측에 삭제를 요청할 대상이 없습니다.
  • 기기 안의 자료는 앱을 삭제하면 모두 삭제됩니다.
  • 앱 설정에서 개별 기록을 지울 수 있습니다.
  • 다운로드 폴더의 백업 파일은 앱을 삭제해도 남습니다. 파일 관리 앱에서 직접 지우십시오.

7. 보안

  • 기기 안의 자료는 안드로이드가 앱별로 격리해 보호하며, 다른 앱이 접근할 수 없습니다.
  • 모든 외부 통신은 HTTPS로만 이루어집니다.

8. 아동

이 앱은 만 16세 미만을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

9. 변경

이 방침이 바뀌면 이 페이지가 갱신되고 상단의 최종 수정일이 바뀝니다. 중요한 변경이 있으면 앱 안에서 알립니다.

Privacy Policy

PLUS2.5 (com.lwd20.traininglog) · Last updated 7 September 2026

Summary. This app has no server. Your training, body and nutrition data are stored on your device only and are never sent to the developer. The developer collects and retains nothing. The only case in which data leaves your device is when you choose to run an AI report, and then it goes directly to the AI provider you selected, using an API key you supplied.

Data the app handles

Training logs, body weight and composition, nutrition intake, app settings, and (optionally) an AI API key. All are held in the app's private storage on your device and are removed when the app is uninstalled.

Health Connect

The app reads two data types from Android Health Connect and never writes to it:

  • android.permission.health.READ_NUTRITION — to compare energy intake against expenditure and to check protein against a target.
  • android.permission.health.READ_WEIGHT — to compute the weekly rate of change and estimate a goal date.

Data obtained through Health Connect stays on the device. It is not used for advertising or marketing, and is not sold or transferred to any third party, including data brokers and information resellers. You may revoke the permissions at any time in Android Settings > Health Connect.

AI reports — the only outbound transfer

This is an optional feature, off by default. It runs only if you enter your own API key and request a report. A summary of your training and body data is then sent to the one provider you selected — Google (Gemini), OpenAI or Anthropic — under your own API key. The developer is not a party to that request and cannot see its contents. The provider's own privacy policy governs what happens next. Your API key is stored on the device only and is excluded from backup files.

Not collected

No accounts, no names or contact details, no location, no contacts or photos, no advertising identifiers, no analytics, no device identifiers. The app contains no analytics or tracking SDK of any kind.

Retention and deletion

The developer holds no data, so there is nothing to request deletion of. Uninstalling the app deletes everything it stored on the device. Backup files written to the Downloads folder survive uninstallation and can be deleted with any file manager.

Security

On-device data is protected by Android's per-app sandbox. All outbound connections use HTTPS.

Children

This app is not directed to children under 16 and does not knowingly collect their personal information.
